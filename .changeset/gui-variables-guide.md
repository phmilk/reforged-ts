The migration note from w3ts 3.x, `migration/behaviour-changes.md`, says under "Rawcodes are typed by Object kind" that a Map project on the Template gets its GUI variables of an object type declared with their kind, so the `number` declarations written by hand for w3ts go away. The Rawcodes guide gains the section it links, "GUI variables of an object type": the Variable Editor types and what each is declared, where the kind comes from, when the declarations are written again, the warning when `war3map.wtg` cannot be read, and how a Map project generated earlier switches to `reforged-map`.
