The docs site has the migration page for w3ts 3.x to reforged-ts 1.0: install and tsconfig, the old-to-new table and the behaviour changes generated from the library's rename map and notes, the Typings changes and what stays the same. `docs:collect` stops the build when the rename map names a symbol the library does not export, a version pair has no page, or a page has no pair. The release package builds on install. Nothing is published.
