`Unit.getflyHeight` and `Unit.setflyHeight` are renamed `Unit.getFlyHeight` and `Unit.setFlyHeight`. `Unit.getIgnoreAlarm` is renamed `Unit.setIgnoreAlarm`, since it changes the setting. `Unit.dropItemFromSlot` is renamed `Unit.moveItemToSlot`, since it moves the item to another inventory slot. `Unit.setUnitAttackCooldown` is removed: `Unit.setAttackCooldown` does the same. Each renamed member calls the same Native with the same arguments. `Unit.removeUnitFromStock` names its parameter `unitId`, the unit type it takes.
