# reforged-ts workspace

pnpm workspace for reforged-ts, a TypeScript API for Warcraft III Reforged custom maps compiled to Lua with typescript-to-lua.

- [`packages/reforged-ts`](packages/reforged-ts): the library.
- [`packages/reforged-types`](packages/reforged-types): the Typings for the game's Natives.

Commands, run from the root after `pnpm install`: `pnpm build`, `pnpm typecheck`, `pnpm typings:generate`, `pnpm typings:check`.
