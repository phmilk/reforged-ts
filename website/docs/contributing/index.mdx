# Contributing

How the project works, for people and for AI coding agents: the words it uses, the decisions it took, the conventions agents follow, and how to add a Wrapper, a lint rule and a Patch. Each page of this section is a file of the repository, copied at every build, so it never differs from what a contributor reads there.

The [Map](https://github.com/phmilk/reforged-ts#map) of the repository's README, on GitHub, lists the diagrams of the workspace (the packages, the CI of a pull request, the release, an issue's life, the development loop and more), each row a flow and the link to its diagram.
