# Migration

One page per major of reforged-ts, from the version before it: install, the old-to-new table of every removed or renamed symbol, the behaviour changes, the Typings changes and what stays the same. The tables and the behaviour changes are generated from the library's rename map and notes, and the site does not build when a pair of the map has no page.
