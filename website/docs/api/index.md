# API

The API reference, generated from the code at every build: every symbol a package exports, with the examples of its doc comments.

- [reforged-ts](./reforged-ts/index.md): the library.
- [reforged-test](./reforged-test/index.md): the Lua test harness, as a Map project's tests import it from `reforged-test/map`.
- [Typings](/typings): the Natives of each supported Patch, the same for every docs version.
