# Typings

The reference of the Typings, `reforged-types`: one subsection per Game version they ship, each generated at every build from the declarations of its Patch. Every Native, Blizzard.j function and global has its page, with its signature, its Jass types, and the `Async` marker of a Native that returns a local-player value. A subsection's index lists them all.
