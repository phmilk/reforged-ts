# Enumeration: MetaKey

Defined in: [handles/input.ts:8](https://github.com/phmilk/reforged-ts/blob/2fc5cb556b8e50100ac48bd504d32d2fe8740ba9/packages/reforged-ts/src/handles/input.ts#L8)

The meta keys `Input.isMetaKeyPressed` asks for, the integer bit flags of
`METAKEY_NONE` to `METAKEY_WINKEYS`; combine them with `|`
(`MetaKey.Shift | MetaKey.Ctrl`).
